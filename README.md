# Aji Terazzo Landing Page

Landing page SvelteKit + Tailwind CSS untuk Aji Terazzo, spesialis jasa pembuatan, pasang, dan poles terazzo area Bali-Lombok.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Static output ada di folder `build/` dan siap deploy ke Cloudflare Pages.
